# Data attribution

`src/data/spells.json` is generated from the [bg3.wiki](https://bg3.wiki) `spells` Cargo table by
`scripts/generate-spells.ts`. The class progressions in `src/data/classes/`, the features and the
option lists were written by hand from the bg3.wiki pages named at the top of each file.
